First-run setup wizard

Four steps, all optional. When you are done, the walkthrough shows the pipeline end to end.

1Service health

Everything below should turn teal within a minute of docker compose up -d. The broker (a JVM) is the slow one.


  


  

    
2Demo data

    
Seed the bundled CARDIO-118 study to see the pipeline work, or skip
       and load your own USDM definition (via POST /api/usdm/load
       or a connector inbox in step 4).

    
    
    

  


  

    
3AI layer

    
The adaptive service turns natural language into broker entities. It
       runs keyless in deterministic stub mode; with an Anthropic API key it
       handles free-form statements.

    
    
To enable the real model: put
       ANTHROPIC_API_KEY=sk-ant-... in a .env file
       next to docker-compose.yaml, then
       docker compose up -d adaptive.

    

  


  

    
4Connectors (optional)

    
Pull study definitions in from, and publish SDTM outputs to, remote
       storage: WebDAV, S3, SFTP, FTP configure right here; Google Drive and
       OneDrive need one OAuth step in the terminal (below). Powered by a
       single rclone bridge, disabled by default.

    

      
The bridge is not running. Enable it with:

      docker compose --profile connectors up -d, then reload
      this page.

    

    

      

      

        
      

      

      
      
      

        
        
      

      
      
      
      
Google Drive / OneDrive: run
        docker compose --profile connectors exec bridge rclone config
        for the guided OAuth flow (or paste a token from
        rclone authorize drive on your workstation). The remote
        then appears in the list above and works with pull and publish.
